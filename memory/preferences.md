# User Preferences (Durable)

These apply to every session unless the user says otherwise.

- **Script language:** Hinglish (Hindi-English mix, the way Indian coaching ads actually speak).
- **Transcript format:** Hook-breakdown — metadata → verbatim transcript → HOOK (first 3s) / PROBLEM-AGITATION / STORY-PROOF / OFFER / CTA → "why it works".
- **Outputs:** Every step of every session saved as its own numbered md file inside the session folder. Nothing lives only in chat.
- **SOP:** Keep `SOP.md` current — it must always describe the actual process used, versioned with a change log.
- **Memory:** `memory/MEMORY.md` must be updated at the end of every session (tool performance, keyword performance, learnings).
- **Repo hygiene:** Create new folders/md files freely whenever the work needs them.
- **Ad research bias:** Longest-running ads = proven winners; prioritize them over new ads.
- **Default deliverable shape:** research library + ready-to-use scripts (not just raw data).
